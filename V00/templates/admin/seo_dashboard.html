How it works

1. Auto Generate Keywords

Extract keywords from article titles, tags, part names, and zone names. Each keyword maps to a target page.

2. Scan & Build Links

Scan all articles/parts content to find keyword matches. Create backlink instances tracking source-to-target relationships.

3. Auto-Render Links

When displaying articles, the system automatically inserts internal links on matched keywords. Old articles get backlinks to new content.
