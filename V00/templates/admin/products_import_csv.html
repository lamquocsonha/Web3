📥 Import Sản phẩm từ CSV

Import hàng loạt sản phẩm từ file CSV (Shopee format)

📋 Format CSV

File CSV cần có các cột sau (header row):

sku,name,url,price,discount,image,desc,category
  • sku: Mã sản phẩm (không bắt buộc)
  • name: Tên sản phẩm (bắt buộc)
  • url: Link sản phẩm (bắt buộc)
  • price: Giá (số, không có dấu phẩy)
  • discount: Giảm giá % (0-100)
  • image: Link ảnh sản phẩm
  • desc: Mô tả ngắn
  • category: Danh mục
