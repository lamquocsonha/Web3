🚀 Hướng dẫn Deploy UniLab lên Server

Chi tiết từng bước cho người mới, không cần kinh nghiệm Python

💡 So sánh: WordPress vs Python (Flask)

Khía cạnhWordPressPython Flask (UniLab)
Server Apache/Nginx + PHP Nginx + Gunicorn (tương tự PHP-FPM)
Database MySQL (cần tạo DB riêng) SQLite (file sẵn, không cần setup)
Upload code FTP/cPanel File Manager Git hoặc SFTP (giống WP)
Cài đặt Chạy installer /wp-admin/install.php Chạy script deploy.sh (1 lần)
Cấu hình domain wp-config.php + .htaccess Nginx config (tự động bởi script)
SSL cPanel AutoSSL hoặc plugin Let's Encrypt (tự động)
Khó khăn ⭐⭐ Dễ (có giao diện) ⭐⭐⭐ Trung bình (dùng terminal)

📌 Tóm lại: Python deploy khó hơn WordPress một chút vì phải dùng terminal commands, nhưng script tự động đã lo hết phần phức tạp. Anh chỉ cần copy-paste commands và nhập domain khi được hỏi.

Tạo Server trên Vultr

💭 Giải thích cho người dùng WordPress:
Shared hosting WordPress = nhà chung cư (bạn share tài nguyên với người khác)
VPS Vultr = căn hộ riêng (bạn có toàn quyền, cài gì cũng được)
→ Cần VPS vì Python app không chạy được trên shared hosting thông thường
Bước 1.1: Đăng ký tài khoản Vultr
  • Vào vultr.com → Sign Up
  • Verify email → Nạp tiền tối thiểu $10 (dùng được 2 tháng với plan $6/tháng)
  • Thanh toán: Credit card, PayPal, hoặc Bitcoin
Bước 1.2: Deploy Instance (tạo server)
Các lựa chọn khi tạo server:
Choose ServerCloud Compute - Shared CPU
LocationSingapore (gần VN nhất, ping ~50ms)
Server ImageUbuntu 22.04 LTS x64
Server Size$6/month → 1 vCPU, 1GB RAM, 25GB SSD, 1TB bandwidth

⏱️ Server sẽ được setup trong 1-2 phút. Vultr sẽ gửi email với:

IP Address: 123.456.789.012
Username: root
Password: AbC123XyZ! (password tự động, rất phức tạp)

🔐 Quan trọng: Copy password này lưu lại, sẽ dùng để SSH vào server

Bước 1.3: Kết nối SSH vào server

SSH = cách để điều khiển server từ xa qua terminal (giống TeamViewer nhưng dùng text commands)

💻 Windows (dùng CMD hoặc PowerShell):
# Nhấn Windows + R, gõ "cmd", Enter
ssh root@123.456.789.012

# Lần đầu sẽ hỏi: Are you sure you want to continue connecting?
# Gõ: yes (rồi Enter)

# Sau đó paste password (Ctrl+V không work, phải chuột phải → Paste)
# Password không hiện gì khi gõ, nhưng vẫn nhập được, Enter là xong
✅ Kết nối thành công khi thấy:
Welcome to Ubuntu 22.04.3 LTS (GNU/Linux 5.15.0-88-generic x86_64)
root@unilab-production:~#

Dòng root@... = đã vào server, giờ commands gõ ở đây sẽ chạy trên server

Trỏ Domain về Server

💭 Giải thích cho người dùng WordPress:
Giống hệt khi trỏ domain về shared hosting WordPress, chỉ khác là thay vì trỏ về Nameserver (ns1.hosting.com), bây giờ trỏ trực tiếp về IP server VPS (123.456.789.012)
Bước 2.1: Lấy IP server
  • Vào Vultr dashboard → Products → Click vào server vừa tạo
  • Copy IP Address (VD: 123.456.789.012)
Bước 2.2: Vào quản lý DNS của domain

Tùy nơi mua domain (GoDaddy, Namecheap, etc.), vào mục DNS Management hoặc DNS Settings

Bước 2.3: Thêm DNS Records
Type Name / Host Value / Points To TTL Mục đích
A @ 123.456.789.012 3600 unilab.vn (domain gốc)
A www 123.456.789.012 3600 www.unilab.vn
A * 123.456.789.012 3600 bike.unilab.vn, car.unilab.vn,... (wildcard)
⏱️ Thời gian DNS lan truyền:
  • 5-30 phút: Thường DNS đã hoạt động (70% trường hợp)
  • 1-2 giờ: Chắc chắn hoạt động toàn cầu (95%)
  • Tối đa 24-48 giờ: Trường hợp hiếm, DNS server chậm update
Bước 2.4: Kiểm tra DNS đã trỏ đúng chưa
# Windows (CMD) hoặc Mac (Terminal):
ping unilab.vn

# Nếu thấy IP của server Vultr = thành công
Reply from 123.456.789.012: bytes=32 time=50ms TTL=64

Upload Code lên Server

💭 Giải thích cho người dùng WordPress:
WordPress: Upload qua FTP (FileZilla) hoặc cPanel File Manager
Python: Dùng Git (như GitHub Desktop) hoặc SFTP (giống FTP)
→ Git nhanh hơn và pro hơn, nhưng SFTP cũng OK nếu quen
Option 1: Dùng Git (Khuyên dùng - nhanh nhất)
# Đảm bảo đang SSH vào server (thấy root@...)
# Nếu chưa SSH, quay lại Bước 1.3

# Cài Git (lần đầu tiên):
apt update && apt install -y git

# Clone code từ repository (thay YOUR_REPO_URL bằng link repo của anh):
git clone https://github.com/username/Web3.git /var/www/unilab

# Vào thư mục code:
cd /var/www/unilab/V00
Option 2: Dùng SFTP (quen thuộc với người dùng WP)
  • Dùng FileZilla, WinSCP, hoặc Cyberduck
  • Protocol: SFTP, Host: IP server, Port: 22, User: root, Password: (password Vultr)
  • Upload thư mục V00 vào /var/www/unilab/ trên server
✅ Upload thành công khi:
# Chạy lệnh này để kiểm tra:
ls -la /var/www/unilab/V00

# Phải thấy các file: app.py, models.py, templates/, static/, ...

Chạy Script Deploy Tự Động

💭 Giải thích cho người dùng WordPress:
WordPress: Truy cập yoursite.com/wp-admin/install.php → click Next → Next → Install
Python: Chạy 1 script bash → script tự động cài hết (Python, Nginx, database, SSL,...)
→ Giống installer WP nhưng chạy qua terminal thay vì trình duyệt
Bước 4.1: Vào thư mục code và chạy deploy.sh
# Đảm bảo đang SSH vào server
cd /var/www/unilab/V00

# Chạy deployment script (thêm quyền execute trước):
chmod +x deploy.sh
sudo bash deploy.sh
🔄 Script sẽ tự động làm gì?
  1. Update Ubuntu và cài Python 3, pip, venv
  2. Cài Nginx (web server, giống Apache trong WP)
  3. Tạo virtual environment Python (môi trường riêng cho app)
  4. Cài tất cả dependencies từ requirements.txt
  5. Setup Gunicorn service (chạy Flask app 24/7)
  6. Configure Nginx làm reverse proxy
  7. Chạy database migrations và seed data
  8. Start services và enable auto-start khi reboot

⏱️ Toàn bộ quá trình: 3-5 phút

Bước 4.2: Nhập domain khi được hỏi

Giữa quá trình deploy, script sẽ hỏi domain:

[?] Enter your domain name (or press Enter to skip): unilab.vn
# Gõ domain rồi nhấn Enter
# Nếu chưa có domain, nhấn Enter để skip (dùng IP tạm)
Bước 4.3: Setup SSL (tùy chọn)
[?] Do you want to setup SSL with Let's Encrypt? (y/n): y
# Gõ 'y' nếu DNS đã trỏ đúng (đợi 30 phút sau khi setup DNS)
# Gõ 'n' nếu muốn dùng HTTP tạm (setup SSL sau cũng được)

🔧 Xử lý lỗi thường gặp

❌ Lỗi: Site không load (502 Bad Gateway)
Nguyên nhân: Flask app chưa chạy hoặc bị crash
# Kiểm tra:
systemctl status unilab

# Nếu inactive → restart:
systemctl restart unilab

# Xem lỗi gì:
journalctl -u unilab -n 50
⚠️ Lỗi: SSL certificate không tạo được
Nguyên nhân: DNS chưa trỏ đúng hoặc port 80/443 bị block
# Kiểm tra DNS:
ping unilab.vn
# Phải thấy IP của server Vultr

# Kiểm tra firewall:
ufw status
# Nếu active → allow ports:
ufw allow 80/tcp
ufw allow 443/tcp

# Setup SSL lại:
certbot --nginx -d unilab.vn -d www.unilab.vn
💡 Lỗi: Database bị lỗi hoặc thiếu bảng
Nguyên nhân: File unilab.db chưa có hoặc schema sai
# Vào thư mục app:
cd /var/www/unilab/V00

# Activate virtual environment:
source venv/bin/activate

# Chạy lại seed data:
python scripts/seed_sidebar_data.py

# Restart app:
systemctl restart unilab
🔄 Lỗi: Code update nhưng site không thay đổi
Nguyên nhân: Gunicorn cache code cũ, cần restart

cd /var/www/unilab/V00

# Restart để load code mới:
systemctl restart unilab
