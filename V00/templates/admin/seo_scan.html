Scan & Build Backlinks

Scan all content to find keyword matches and create backlink instances. This includes scanning older articles to add links to newer content.

Dashboard Keywords Instances Auto Generate Scan & Build

How the scan works:

  • Loads all active keywords for the selected vertical
  • Scans each article/part content for keyword matches (case-insensitive)
  • Self-linking is prevented — articles won't link to themselves
  • Creates a BacklinkInstance for each match (source → target)
  • Duplicates are skipped — same source+keyword won't create multiple instances
  • Retroactive: Old articles get links to newer content that was added after them
  • Links are rendered automatically when articles are displayed on the frontend
Recommended workflow:
  1. First, Auto Generate Keywords from your content
  2. Review and adjust keywords in the Keywords page
  3. Then run this scan to build all backlink instances
  4. Re-run the scan whenever you add new articles or keywords
